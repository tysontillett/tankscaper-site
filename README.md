# Tankscaper website

The website for Tankscaper, at https://tankscapergame.com

- index.html: the main page
- privacy.html: privacy policy
- support.html: support page
- 404.html: shown when a page is not found
- img/share.jpg: the picture shown when the link is shared
- favicon.ico, favicon-96.png, apple-touch-icon.png, icon-192.png, icon-512.png: the site icon
- robots.txt, sitemap.xml: tell search engines what is here
- CNAME: tells GitHub the site lives at tankscapergame.com (do not delete)
